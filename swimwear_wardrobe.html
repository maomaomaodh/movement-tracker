备份 / 恢复数据

导出 JSON 会包含泳衣信息、压缩后的照片和穿着日期。建议把文件存到“文件”App 的 iCloud Drive。换设备或清理浏览器前，可从备份恢复。

注意：网页托管在 GitHub Pages 并不会自动同步数据到 iCloud。此版本使用本机浏览器存储，iCloud 通过手动备份文件实现保管与迁移。

保存与 iCloud 说明

怎么在 iPhone 上用

  1. 用 Safari 打开这个网页。
  2. 点分享按钮，选择“添加到主屏幕”。
  3. 以后从主屏幕打开，添加泳衣、选照片或记录穿着。

数据保存在哪里？

当前版本保存在这台 iPhone 的 Safari 网页数据中。它不需要账号或服务器，但清理 Safari 网站数据、换浏览器或换设备时，数据可能无法自动带过去。

如何利用 iCloud？

在“备份 / 恢复”里导出完整 JSON，在系统分享面板选择“存储到文件”→ iCloud Drive。更新数据后重新导出并替换旧备份。换设备时从 iCloud Drive 选择备份文件导入。

穿着次数怎么记？

如果只知道总次数，在编辑时填入“过去穿过几次”即可；如果想看每次日期，使用“补录具体穿着日期”或卡片上的“穿过了”逐条记录。已知总次数与逐条日期是分开的：填写总次数不会自动生成虚构日期。

照片隐私

照片压缩后保存在本机网页数据及导出的备份里，不会由此页面主动上传到服务器。请妥善保管包含照片的备份文件。
